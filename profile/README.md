허깅페이스 문서 번역과 다양한 리소스 제작을 통해 더 많은 사람들이 Hugging Face를 활용해 AI 기술을 쉽게 접할 수 있도록 돕고 있습니다.
또한 팀원들과 함께 다양한 프로젝트를 진행하며, 서로의 역량을 성장시키는 것을 목표로 합니다.
